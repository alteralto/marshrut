# Документы

| Папка | Что лежит |
|---|---|
| `case/` | Документы, выданные организаторами хакатона (приказы и регламенты МФТИ, бланки), и два открытых регламента с сайта МФТИ: материальная помощь обучающимся и переход с платного обучения на бесплатное. `case/manifest.json` задаёт идентификаторы и адреса источников. Эти документы читаются при сборке образа и составляют базу приложения. |
| `extracted/` | Распознанный текст сканов из `case/`, по одному файлу на документ (имя — SHA-256 исходного файла). Если файл есть, сборка не распознаёт скан заново; если его удалить, скан будет распознан Tesseract. |
| `text/` | Тексты 17 открытых регламентов МФТИ и других вузов для отложенного набора `rag/fixtures/real-test.json`: на этих документах поиск не настраивался. Источники — `text/manifest.json`. |

Открытые регламенты взяты с разделов «Сведения об образовательной организации» сайтов вузов. Официальные документы не охраняются авторским правом (ст. 1259 ГК РФ).

Повторить проверку на отложенном наборе:

```sh
node rag/cli.js ingest corpus/text --out rag/data/real-index.json --no-embed
node rag/eval/run-eval.js --questions rag/fixtures/real-test.json --index rag/data/real-index.json --mode extractive
```
