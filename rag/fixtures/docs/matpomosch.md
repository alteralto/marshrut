# Положение о материальной поддержке обучающихся

Тестовый документ для разработки. Не является действующим локальным актом МФТИ.

## 1. Общие положения

1.1. Материальная поддержка оказывается обучающимся по очной форме обучения за счёт средств стипендиального фонда.

1.2. Материальная поддержка оказывается не чаще одного раза в семестр.

## 2. Основания для оказания материальной поддержки

2.1. Материальная поддержка может быть оказана в следующих случаях:
1) рождение ребёнка;
2) тяжёлое материальное положение;
3) утрата имущества в результате пожара или стихийного бедствия;
4) необходимость дорогостоящего лечения.

## 3. Порядок обращения

3.1. Обучающийся подаёт заявление на имя председателя стипендиальной комиссии через профсоюзного организатора факультета.

3.2. К заявлению прилагаются документы, подтверждающие основание для оказания материальной поддержки: свидетельство о рождении ребёнка, справка о доходах семьи, справка из МЧС или медицинские документы.

3.3. Стипендиальная комиссия рассматривает заявления на ежемесячном заседании и принимает решение о размере материальной поддержки.

3.4. На основании решения комиссии издаётся приказ, и материальная поддержка перечисляется на банковскую карту обучающегося вместе с ближайшей выплатой стипендии.
